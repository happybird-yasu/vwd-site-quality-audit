# 夜間・地図データ検査（本番への書込みなし）

対象はサイトマップに実在する12分類（人口流動は今回除外）。駅、駅乗降客ランキング、港、空港、温泉、学校、医療機関、道路交通量、高齢化率、感染症、鉱物、ホテル・旅館。作成時のサイトマップは640記事、対象590記事、5言語。未知のテーマがあれば候補一覧に残す。

## 実行と朝の確認

GitHub Actions の `Overnight map data integrity audit (12 themes, read-only)` を実行する。専用ブランチ `data-integrity-audit` への検査コードのpushでも起動する。

- PCを切った後もGitHub側で実行される。一晩だけの実行で、定期実行は設定しない。
- 最優先の高齢化率・感染症から、最大2テーマを並行実行。リクエストは各ジョブ3秒間隔、最大2試行。サイトマップ・公開記事・公開埋込地図・カード・参照データをGETする。
- 取得・解析エラーを個別に記録し、次のファイルへ進む。テーマ自体の異常終了があっても他テーマを中止しない。途中結果を定期保存し、最終集計は失敗時も動く。
- 1テーマ150分、取得1,800リソースを上限とし、上限到達は未処理件数を明示。公式照合用の時間を別途確保。無限リトライはしない。
- `morning-data-audit-summary` の `report.md` が朝の入口。各テーマの `report.json`、`checks.json`、`fetch_manifest.json` で問題と原本SHA256を確認できる。原本応答は圧縮して保存する。
- 12分類のジョブが全て緑でも「全数値が公式値と一致」とは意味しない。取得失敗・不整合はレポート内のデータとして扱い、検査を継続させる設計である。

## 実装済みの検査範囲

共通：取得可否、JSON破損・重複キー・非有限数値、GeoJSON座標範囲・ポリゴン閉環、緯度経度、読取可能なJSON形式の埋込データ。JavaScriptは実行しない。サイトの動的コードを推測実行せず、計算式で生成される未追跡パスは残件にする。WordPress API・管理画面にはアクセスしない。robots.txtの禁止を尊重し、robots取得不能も未確認として残す。

項目別の内部検査：空港の国際＋国内＝総数、港の外航＋内航＝総数、温泉の利用＋未利用＝源泉総数、学校の本校・分校／設置者別内訳／都道府県合計と全国値、高齢化率の年齢既知分母と再計算率。1965年学校統計の沖縄除外を欠測のまま扱う。欠測・秘匿・非数値をゼロで埋めない。

公式数値照合：

- **高齢化率**：公開中の2015・2020・2025年の各市区町村の3年齢区分を、対象年を固定して統計ダッシュボードAPIから新規取得し照合。2015年の2件のコード変更は、公開メタデータが宣言する対応だけを使用。公式応答の年も検査する。率は年齢不詳を除く既知人口を分母として別途検算。
- **感染症**：実際に読めた週次データについて、掲載データ自身が明示する当該週の公式CSVを取得し、疾病名・年・週・都道府県・指標を対応させて報告数／定点当たりを照合。定点当たり値を合計しない。月・季節は明示された週番号のまとまりから件数合計／週率の単純平均（小数4桁）を別枠で再計算する。これは暦月の公式値の検証ではない。公式CSVの「-」など非数値は勝手にゼロにしない。
- **その他10分類**：公式出典リンク・元データの収集と内部整合を検査する段階。原典の全数値との照合はまだ未実装で、`not_implemented_for_this_theme` と明記する。出典にアクセスできても一致とは判定しない。

全国の全境界変遷、各テーマ固有の集計方法・単位、ブラウザでの最終描画は、この静的チェックだけでは保証しない。エラーがない項目と未確認の項目を分離して、次の公式照合作業に使う。

## ローカル動作確認

```text
python -m unittest data_audit.test_audit -v
python -m data_audit.run discover --out inventory
python -m data_audit.run audit --theme airport --targets inventory/targets.json --out results/airport
python -m data_audit.run merge --targets inventory/targets.json --inputs results --out morning
```

実装時の確認：12テスト通過（壊れた合計、欠測、週違い、病気の指標取り違え、取得失敗後の継続、結果欠落時の誤判定防止を含む）。高齢化率の公式API照合17,031値が一致。空港の実際の30記事と参照データの短時間試行を実施し、上限時に残件を明示することを確認。
